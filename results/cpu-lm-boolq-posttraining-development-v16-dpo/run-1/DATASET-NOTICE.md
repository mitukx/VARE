# BoolQ dataset attribution

The BoolQ questions, passages, labels, and derived artifacts containing their text are from Google Research's BoolQ dataset and are attributed to:

Christopher Clark, Kenton Lee, Ming-Wei Chang, Tom Kwiatkowski, Michael Collins, and Kristina Toutanova. “BoolQ: Exploring the Surprising Difficulty of Natural Yes/No Questions.” NAACL 2019. https://arxiv.org/abs/1905.10044

The dataset card for `google/boolq` identifies the dataset license as Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0): https://huggingface.co/datasets/google/boolq

This notice applies to BoolQ-derived question/passage data and artifacts that contain or encode the dataset text. VARE source code remains under the repository's Apache-2.0 license. The full BoolQ dataset is not copied into this repository.
