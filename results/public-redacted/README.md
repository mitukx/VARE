# Redacted public copies of files with host paths

Many committed result, protocol and documentation files record absolute paths of the hosts that
produced them, such as user home directories, per-session working directories, per-user temporary
directories and local tool prefixes. The originals are hash-bound evidence (`SHA256SUMS` files,
protocol locks, review records) and stay unchanged. This directory holds derived public copies in
which those host paths are replaced by placeholders. Each copy keeps the original's
repository-relative path under `results/public-redacted/`, so
`results/foo/run-1/x.log` is copied to `results/public-redacted/results/foo/run-1/x.log`.

The copies are derivatives, not evidence. Hash checks, re-analysis and audits should use the
originals. Use a copy only where a file is quoted or redistributed.

This tree is the repository-wide counterpart of `results/learning-pipeline-v1/public-redacted/`.
Files that tree already covers are listed as excluded below rather than copied twice. Both trees
use the same method and verification pattern.

## Layout

All copies live in this one tree rather than in a `public-redacted/` directory inside each result
directory, for these reasons:

* About 150 result directories are affected, together with `docs/`, `protocols/`, `research/`,
  `evidence/` and `requirements/`. Per-directory trees would scatter copies and mapping files
  across all of them.
* Nothing is added inside an existing result directory, so no per-run `SHA256SUMS` manifest,
  file-count check or source inventory sees a new file.
* One `MAPPING.json` and one table cover every file, and one `--check` run checks the whole
  repository.

## Redaction rule

The copies are produced by `scripts/redact_host_paths_public.py`.

* An ordered list of regular-expression substitutions is applied to the UTF-8 text of each
  original. Each rule runs on the output of the previous one, so the result is deterministic and
  idempotent.
* Path components are matched generically. Neither the script nor `MAPPING.json` spells a
  host-specific directory name. The exact patterns are in `MAPPING.json` under
  `rule.substitutions`.
* Only the host-specific prefix is replaced. The rest of each path, such as
  `<SESSION_ROOT>/work/VARE/tests/test_engine.py`, is kept, because it is the layout inside that
  working directory.
* Where a log formatter truncated a path with `...` or `…`, the prefix up to the ellipsis is
  replaced and the ellipsis is kept.
* JSON and JSON Lines copies must parse to the same structure as the original once the same
  substitution is applied to every string. A `.json` file that is not JSON (captured stdout with
  a trailing text line) is copied as text.
* After substitution, a copy must not match the host-path pattern in
  `rule.verification_pattern`, apart from the non-host forms below. If any other match remains,
  generation fails rather than leaving it in place.

| Placeholder | Meaning | Replaced prefix |
|---|---|---|
| `<SESSION_ROOT>` | per-session working directory on a development host | `/Users/<user>/Documents/<app>/<date>/<label>` on macOS, `/workspace/scratch/<id>` on Linux |
| `<HF_HUB_CACHE>` | Hugging Face hub cache directory in the user's home directory | `/Users/<user>/.cache/huggingface/hub` |
| `<HOME>` | user home directory on a macOS development host | `/Users/<user>` |
| `<TMPDIR>` | per-user temporary directory on a macOS host (`$TMPDIR`) | `/private/var/folders/<a>/<b>/T`, `/var/folders/<a>/<b>/T` |
| `<TMP>` | system temporary directory on a macOS host (`/tmp`) | `/private/tmp` |
| `<HOMEBREW_PREFIX>` | Homebrew installation prefix on a macOS host | `/opt/homebrew` |
| `<REPO_ROOT>` | repository checkout on a mounted data volume | `/mnt/<volume>/VARE` |
| `<DATA_CACHE>` | dataset cache directory on the data-preparation host | `/workspace/<label>/lp-cache` |

`<HF_HUB_CACHE>`, `<REPO_ROOT>` and `<DATA_CACHE>` mean the same as in
`results/learning-pipeline-v1/public-redacted/`. `<RUN_ROOT>` is not needed here.

### Non-host forms

The verification pattern also matches some absolute paths that do not describe a host of this
project. They are kept verbatim in copies, and a file that contains only these forms gets no copy.

| Form | Meaning |
|---|---|
| `/workspace/<file>`, `/workspace/src` | file at the evaluation-container mount point |
| `/home/runner/work/...` | GitHub-hosted Linux runner checkout |
| `/Users/runner/...` | upstream build path on a GitHub-hosted macOS runner (embedded in wheels and tracebacks) |
| `/home/conda/feedstock_root/...` | upstream conda-forge build path |
| `/root/<name>` | reviewer agent identifier, not a file path |
| `/home/user/src/...` | path written by a model inside its sandboxed task workspace |
| `/private/var/folders`, `/private/var/folders/...` | generic macOS temporary-directory root named in prose |

Relative paths that contain one of these names, such as `task/workspace/public` or
`../work/private/asdiv.parquet`, are not absolute and are not matched.

## Verification

```
python scripts/redact_host_paths_public.py --check
pytest tests/test_redact_host_paths_public.py
```

`--check` fails (exit code 1) if any of the following holds:

* An original no longer has the sha256 recorded in `MAPPING.json`.
* A tracked file contains a host path but has neither a copy nor an exclusion.
* A copy, `MAPPING.json` or the table below differs from its regenerated form.
* A copy contains a host path.

`--write` regenerates the copies, `MAPPING.json` and the table. It refuses to write while any
copy would still contain a host path.

## Mapping

The same data, with byte sizes and totals, is in `MAPPING.json`. Copies are listed by original
path; each copy is at `results/public-redacted/<original>`.

Files with a host path that get no copy are listed under "Excluded" with the reason:

* Executable source under `scripts/`, `tests/`, `src/` and `benchmarks/`. A copy with
  placeholders would not run, so a host literal there needs a source change instead.
* The redaction scripts and their tests, where the paths are patterns and synthetic fixtures.
* Files already copied by `scripts/redact_learning_pipeline_v1_public.py`.
* Files containing only non-host forms.
* Files containing third-party repository references, withheld pending separate review. They
  are listed by explicit path in `PENDING_REVIEW` in the script; their originals are unchanged.
* A file whose copy would exceed the 1 MiB tracked-blob budget enforced by
  `scripts/check_tracked_blob_budget.py`.
