# Square a JSON integer

`solve.py` reads one JSON object from standard input. The object has an integer field `n`. The program must write exactly one JSON object whose `value` field is `n` squared, and it must write nothing else.

The current program is incorrect. Change only `solve.py`.

Example: when `n` is 3, `value` is 9.

Further checks use other integers. Those checks are not files in this workspace.
